# Elektro Andrade – Website-Prototyp

Prototyp der Website für Elektro Andrade, Elektromeisterbetrieb in Heilbronn.

**Live ansehen:** über GitHub Pages (Link in der Repository-Beschreibung).

## Aufbau

- `src/page.html` – Quelltext der Seite (HTML, CSS, JS)
- `src/icons/` – SVG-Icons, werden beim Build als Sprite eingebettet
- `assets/` – Fotos (Platzhalter)
- `index.html` – gebaute Seite, wird von GitHub Pages ausgeliefert

## Bauen

```
node build.js
```

Fotos sind Platzhalter. Datenschutzerklärung und Angaben zur Handwerkskammer folgen.
